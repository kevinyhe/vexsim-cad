# vexsim-cad

The Override field shapes now come with
[vexsim](https://github.com/kevinyhe/vexsim), in its `cad/override/`. Clone
vexsim and they are there. This repository is archived.

The files here are the same as vexsim's at the time it took them
(`shapes.json`, `field.json`, `view.json`, `view.bin`), cut from
[VEX's Override field CAD](https://content.vexrobotics.com/docs/2026-2027/override/files/v5rc-override-fieldcad.zip)
by vexsim's `tools/override_cad.py`.
